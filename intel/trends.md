# Tendencias Relevantes

*Last updated: 2026-04-03*

## IA
- **RAG self-hosted:** ChromaDB, Qdrant, Weaviate — los devs migran de SaaS a local por privacidad
- **Agentes especializados:** El futuro no es un agente generalista sino squads (como las de Hans)
- **OpenClaw:** Framework de agentes personal creciendo — clawhub.ai para skills marketplace
- **Modelos chinos (GLM/Z.ai):** Costo más bajo que OpenAI, calidad competitiva, contexto enorme (200k tokens)
- **OCR everywhere:** Tesseract + LLM permite indexar imágenes y video como texto

## Data Engineering
- **Kafka + Avro:** Stack estándar en empresas (Hans tiene experiencia con esto en Kayser-V)
- **Real-time streaming:** Crece demanda de pipelines en tiempo real
- **dbt + BigQuery:** ETL moderno para reporting (Hans trabaja con esto en TI Partner)

## Linux / Infraestructura
- **Arch Linux:** Popular entre power users — los scripts de Hans tienen audiencia natural
- **NUC como home server:** Trend creciente — bajo consumo, siempre-on
- **Tailscale:** VPN mesh para conectar todo sin configurar routers
- **Cloudflare Tunnel:** Exponer servicios locales sin abrir puertos (ya usándolo)

## DevOps
- **Docker compose:** Standard para self-hosted
- **uv (Python):** Reemplazando pip/venv — más rápido, maneja versiones de Python
- **systemd timers:** Reemplazando cron en distros modernas
